# 🎯 Полная настройка Female-Fabric

## ШАГ 1️⃣: Установка всех программ

Есть **2 способа**:

### Способ A: Автоматическая установка (рекомендуется)

1. **Откройте командную строку (cmd.exe) от имени администратора:**
   - Нажмите `Win + R`
   - Введите `cmd`
   - Нажмите `Ctrl + Shift + Enter` (от имени администратора)

2. **Перейдите в папку проекта:**
   ```
   cd C:\Users\Pc\.gemini\antigravity\scratch\female-fabric
   ```

3. **Запустите установщик:**
   ```
   install.bat
   ```

   Скрипт автоматически:
   - ✓ Проверит что уже установлено
   - ✓ Скачает Python (если нужно)
   - ✓ Скачает Node.js (если нужно)
   - ✓ Установит все Python пакеты
   - ✓ Установит Wrangler (для Cloudflare)
   - ✓ Установит uv (Python package manager)

### Способ B: Ручная установка

Если Способ A не сработал:

1. **Установите Python:**
   - Скачайте с https://python.org (версия 3.11 или выше)
   - Во время установки **обязательно** включите "Add Python to PATH"

2. **Установите Node.js:**
   - Скачайте с https://nodejs.org (LTS версия)
   - Установите как обычно

3. **Откройте командную строку и выполните:**
   ```
   pip install -r requirements.txt
   npm install -g wrangler
   pip install uv
   ```

## ШАГ 2️⃣: Локальный запуск приложения

Есть **2 способа**:

### Способ A: Простой (через батник)

Просто дважды кликните на файл **`run-local.bat`**

Приложение откроется на http://localhost:8000

### Способ B: Через командную строку

1. Откройте cmd.exe
2. Перейдите в папку проекта:
   ```
   cd C:\Users\Pc\.gemini\antigravity\scratch\female-fabric
   ```
3. Запустите:
   ```
   python run.py
   ```

### Тестовые учетные записи:

## ❓ Что если что-то не работает?

### "Python не найден"
- Переустановите Python с https://python.org
- **Важно:** включите "Add Python to PATH"
- Перезагрузите компьютер после установки

### "Не могу запустить install.bat"
- Откройте cmd.exe **от имени администратора**
- Перейдите в папку проекта
- Запустите `install.bat` вручную

### Ошибка при запуске приложения
```
python run.py
```
Проверьте что:
- Файл `.env` существует (скопируйте из `.env.example` если нужно)
- Python установлен: `python --version`
- Зависимости установлены: `pip install -r requirements.txt`

### Какой-то пакет не устанавливается
Попробуйте переустановку:
```
pip install --force-reinstall -r requirements.txt
```

## 📁 Структура файлов

```
female-fabric/
├── install.bat           ← Кликните чтобы установить все
├── install.ps1           ← PowerShell версия установщика
├── run-local.bat         ← Кликните чтобы запустить приложение
├── run-local.ps1         ← PowerShell версия запуска
├── run.py                ← Запуск через Python (если батник не работает)
├── test_app.py           ← Запуск тестов
│
├── .env                  ← Конфигурация (создавайте из .env.example)
├── .env.example          ← Шаблон конфигурации
│
├── app/                  ← Основной код приложения
├── public/               ← Статика для Cloudflare
├── src/                  ← Cloudflare Worker код
│
├── requirements.txt      ← Python зависимости
├── pyproject.toml        ← Python проект конфиг
├── wrangler.jsonc        ← Cloudflare Workers конфиг
│
├── SETUP.md              ← Этот файл (быстрая настройка)
├── QUICKSTART.md         ← Детальные инструкции
├── SUPABASE_SETUP.md     ← Настройка базы данных
└── INSTALL_TOOLS.md      ← Информация о каждом инструменте
```
