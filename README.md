# Female-Fabric — Интернет-магазин женской одежды

Современный, быстрый и адаптивный коммерческий интернет-магазин женской одежды премиум-класса **Female-Fabric**. 

Разработан в строгом соответствии с ТЗ на базе **FastAPI**, **SQLAlchemy 2.0 ORM**, **SQLite**, **Pydantic v2**, безопасной аутентификации **JWT (bcrypt)** и элегантного адаптивного фронтенда (HTML5, Tailwind CSS, модульный JS, Lucide Icons).

---

## 🌟 Основные возможности и функционал

### 1. Главная страница
* Элегантная шапка с живым поиском (автокомплит на лету), счетчиком корзины и меню профиля.
* Большой адаптивный Hero-баннер новой коллекции.
* Сетка категорий с интерактивным масштабированием обложек.
* Блоки популярных моделей (Featured) и новых поступлений (New Arrivals).
* Промо-баннер весенней коллекции со скидкой.
* Блок преимуществ магазина (Примерка перед покупкой, Быстрая доставка, 100% натуральные ткани, Легкий возврат).
* Подвал со ссылками, формой подписки и контактами.

### 2. Каталог и фильтры
* Категории одежды с динамическим подсчетом товаров.
* Живой поиск по названию, артикулу и описанию.
* Диапазон цен (от / до) с мгновенным пересчетом.
* Фильтр по доступным размерам (XS, S, M, L, XL, One Size).
* Фильтр по цветам (с цветовыми маркерами).
* Фильтры «Только в наличии» и «Товары со скидкой».
* Сортировка: по новизне, по популярности, сначала дешевле, сначала дороже, по размеру скидки.
* Постраничная пагинация.
* Карточки товаров с бейджами скидок (-25%), бейджами NEW, быстрыми кнопками в избранное и выбором размеров.

### 3. Страница товара
* Галерея фотографий с превью и переключением миниатюр.
* Артикул (SKU), категория, актуальная цена, старая цена, бейдж скидки.
* Выбор размера и цвета с отображением точного остатка на складе в реальном времени.
* Модальное окно **«Таблица размеров»** (обхваты груди, талии и бедер по стандартам RU/EU).
* Подробное описание и спецификация (состав ткани, посадка, сезон, рекомендации по уходу).
* Кнопки «Добавить в корзину» и **«Купить в 1 клик»** (с модальной формой).
* Аккордеоны условий доставки и возврата.
* Блок рекомендаций «Вам также может понравиться».

### 4. Корзина и Синхронизация
* Добавление, удаление, изменение количества товаров.
* Расчет скидок, суммы заказа и шкалы бесплатной доставки (бесплатно от 5 000 ₽).
* Выдвижная боковая мини-корзина (Side Drawer) на всех страницах.
* Полноразмерная страница корзины (`/cart`).
* Синхронизация корзины гостя из `localStorage` с базой данных при авторизации.

### 5. Оформление заказа (Checkout)
* Поля: Имя, Фамилия, Номер телефона, Email, Город, Адрес доставки, Комментарий.
* Способы доставки: Курьер с примеркой, СДЭК / ПВЗ, Почта России, Самовывоз из бутика.
* Способы оплаты: Банковской картой онлайн, СБП, При получении, Долями (4 платежа).
* Автозаполнение данных для авторизованных клиентов из сохраненных адресов.
* Генерация уникального номера заказа вида `FF-2026-XXXX`.
* Автоматическое списание складских остатков и очистка корзины.
* Страница успешного заказа (`/order-success`) с деталями.

### 6. Личный кабинет пользователя (`/profile`)
* **История заказов**: список всех покупок с составом, ценами и статусами:
  * `Новый` → `Подтверждён` → `Собирается` → `Отправлен` → `Доставлен` / `Отменён`.
* **Избранное (Wishlist)**: сохранение понравившихся товаров в 1 клик.
* **Мои данные**: редактирование имени, телефона, email и безопасная смена пароля.
* **Адреса доставки**: добавление, удаление и выбор адреса по умолчанию.

### 7. Административная панель (`/admin`)
* Доступ защищен на уровне ролей (`role == 'admin'`), возврат 403 Forbidden для обычных пользователей.
* **Дашборд**: аналитика выручки, общее число заказов, новые заказы, активные клиенты, остатки товаров.
* **Товары**: CRUD товаров, добавление нескольких фото, загрузка изображений с валидацией MIME/размера, управление размерами/цветами и остатками, переключение видимости в каталоге.
* **Категории**: создание, редактирование, изменение порядка отображения, удаление.
* **Заказы**: фильтрация по статусам, просмотр полной информации о клиенте и позициях, изменение статуса заказа с мгновенным сохранением в БД.
* **Пользователи**: список зарегистрированных клиентов, даты регистрации, сумма покупок, управление статусом аккаунта.

### 8. SEO и Оптимизация
* Schema.org разметка: `ClothingStore` / `Organization` на главной и `Product` на страницах товаров.
* Мета-теги Open Graph, canonical URL, robots.txt и sitemap.xml.
* Быстрая загрузка без тяжелых внешних сборщиков, Skeleton Loading.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python run.py
```
Сервер будет доступен по адресу: **http://localhost:8000**  
Интерактивная документация Swagger: **http://localhost:8000/docs**

### 3. Запуск тестов
```bash
python test_app.py
```
