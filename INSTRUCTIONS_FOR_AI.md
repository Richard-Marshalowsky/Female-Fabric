# ПРАВИЛА ТА ИНСТРУКЦИЯ ДЛЯ ИИ-РАЗРАБОТЧИКОВ (FEMALE-FABRIC)

> **КРИТИЧЕСКИ ВАЖНО ДЛЯ ВСЕХ ИИ И РАЗРАБОТЧИКОВ:**
> Проект полностью адаптирован под украинских пользователей (UA по умолчанию), содержит двуязычный переключатель (UA ↔ RU) и разворачивается на **Vercel** + поддерживается локальный запуск на FastAPI. 

---

## 1. ТЕКУЩАЯ АРХИТЕКТУРА И СТЕК

- **Backend**: Python 3.10+ / FastAPI / SQLAlchemy / Pydantic.
- **Frontend**: Чистый HTML5 + Tailwind CSS (CDN) + Vanilla JS (без тяжёлых фреймворков).
- **Deployment**: Vercel Serverless Python (`api/index.py` + `vercel.json`).
- **Database**: SQLite по умолчанию для локальной разработки (`female_fabric_db`), заменяется на PostgreSQL / Supabase для продакшена через `DATABASE_URL`.
- **Локальный запуск**: `python run.py` -> `http://localhost:8000`.
- **Тесты**: `python test_app.py` (все 7 наборов должны всегда проходить со 100% успехом).

## 2. ГЛАВНЫЕ ПРАВИЛА (СТРОГО СОБЛЮДАТЬ!)

### ❌ 1. НЕ МЕНЯТЬ И НЕ ЛОМАТЬ ДИЗАЙН И ВЕРСТКУ
- Шаблоны в `app/templates/` и их копии в `public/` содержат утверждённый, финальный премиальный дизайн Female-Fabric.
- Запрещено менять стили, верстку, цветовые решения, переписывать проект с нуля или использовать сторонние UI библиотеки без явной просьбы пользователя.

### 🇺🇦 2. ЯЗЫК И ЛОКАЛИЗАЦИЯ (i18n)
- **Основной язык сайта**: Украинский (`uk`).
- **Валюта**: Гривня (`₴`).
- **Доставка**: Нова Пошта (отделения, курьер, почтоматы), Укрпошта Экспресс.
- **Контакты**: Телефон `+38 (097) 123-45-67`, почта `support@female-fabric.ua`, города Украины (Киев, Львов, Одесса и др.).
- **Переключатель языков (UA / RU)**:
  - Словарь находится в `app/static/js/i18n.js` (дублируется в `public/static/js/i18n.js`).
  - Переключатель в шапке работает через `app/static/js/lang-switcher.js`.
  - Все текстовые элементы в HTML должны содержать атрибут `data-i18n="key_name"`.
  - При добавлении новых текстов **ОБЯЗАТЕЛЬНО** добавлять ключи и в `ua`, и в `ru` ветку `i18n.js`!

### 🔄 3. СИНХРОНИЗАЦИЯ ТЕМПЛЕЙТОВ И СТАТИКИ
- Файлы шаблонов находятся в `app/templates/`.
- Папка `public/` служит для статической раздачи и Vercel.
- **ВАЖНО**: При любом изменении файла в `app/templates/X.html` или `app/static/...` скопируйте изменения в `public/X.html` и `public/static/...`.

### 🚀 4. ДЕПЛОЙ НА VERCEL
- Точка входа для Vercel: `api/index.py` (импортирует `app.main:app`).
- Маршрутизация задаётся в `vercel.json`.
- Переменные окружения задаются в Vercel Dashboard (не хранить секреты в репозитории).
